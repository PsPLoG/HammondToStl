# PEDALFORM — Hammond-style pedal enclosure studio

브라우저에서 기타 이펙터용 **3D 프린팅 하몬드 유사 규격 케이스**를 설계하고, **본체·하판(+ 시험용 출력 나사) STL을 한 번에 ZIP으로 다운로드**하는 React / Three.js 웹 앱입니다.

> **상태: 기능형 프로토타입 / 치수 검증 필요.** 실제 Hammond 다이캐스트 케이스를 정확히 재현하거나, 특정 부품·프린터에서의 기계적 호환성을 보증하지 않습니다. 제품 제작 전 측정과 테스트 출력이 필요합니다.

## v0.4.2 확인 기능: 3D 코너 보강부 강조 및 로딩 오류 표시

- **실제 CSG 메쉬 테스트:** 1590A·1590B·125B·1590BB의 네 코너마다 원기둥 바로 밖과 벽 사이 점을 수직 레이캐스트하여, 본체 메쉬가 하판면(Y=0)까지 채워져 있는지 확인합니다. 기존 좌표 기반 테스트에 추가한 실제 형상 검사입니다.
- **3D 코너 보강부 강조:** 3D 미리보기 우측 위 **세 번째 아이콘(겹친 층 모양)**으로 보강부를 연두색 반투명 볼륨으로 강조/해제합니다. 이 강조 메쉬는 STL과 동일한 코너 웹 형상 생성 함수를 사용하지만 **화면 표시용 보조 레이어**이고 STL에 중복 포함되지 않습니다.
- **버전 표시:** 상단에 v0.4.2를 표시해 이전 캐시 버전과 구별합니다.
- **오류 안내:** JavaScript 화면 렌더 예외가 발생한 경우 오류 내용을 표시하고, 앱 스크립트가 아예 로드되지 않으면 기본 로딩 문구가 남습니다.

## v0.4.1 수정: 나사 기둥과 벽 사이 공간 완전 충전

- 기존 보강 직사각형이 내벽에서 0.35mm 안쪽에 멈추던 문제를 해결했습니다.
- 기둥과 벽 사이를 메우는 보강부는 **라운드 외곽선을 따라가는 단단한 코너 폴리곤**으로 모델링하며, 두 내벽 **안쪽으로 깊이 겹치도록** 연장합니다.
- 보강부는 하판 접합면에서 상판 내부 천장까지 연속됩니다. 외곽 형상보다 0.65mm 안쪽으로만 형성되어 외부 모서리는 튀어나오지 않습니다.
- 3D 프린팅에 앞서 CSG 출력 결과가 기밀한지(워터타이트), 나사 체결 강도가 충분한지 슬라이서 및 시제품으로 확인하세요.

## v0.4 화면 구성: 상단 메뉴 내비게이션

- 기존 왼쪽 세로 메뉴를 제거하고 **상단의 케이스 / 체결 방식 / 부품 추가 / 노브 프리셋 / PCB** 메뉴로 이동했습니다.
- 클릭 시 각 메뉴의 기존 컨트롤이 드롭다운으로 열립니다. 메뉴 밖 클릭 또는 Escape로 닫습니다.
- 편집 영역은 기존 왼쪽 메뉴가 차지하던 폭만큼 넓어졌고 오른쪽 부품 속성 패널은 유지됩니다.
- 작은 화면에서는 상단 5개 메뉴를 균등하게 배치하고, 드롭다운은 화면 너비에 맞춰 표시합니다.

## v0.3 추가 기능: PCB 배치, 1~6노브 프리셋, 벽 결합형 기둥

- **PCB 공간 검토:** 원하는 너비·길이·두께·높이·위치로 PCB를 추가하고 삭제합니다. 상판 2D에서 드래그하고, 3D 내부 보기에서 녹색 기판을 확인합니다. 최대 10장, JSON 저장/불러오기에도 포함됩니다. 기판은 **공간 검토용 가상 모델**이므로 케이스 STL에 포함되지 않고 전자기판 제조용 데이터도 아닙니다.
- **노브 프리셋 1~6개:** 상판 포텐셔미터만 규칙적으로 자동 배치합니다. 풋스위치·LED·잭 등 기존 부품은 보존하고 케이스 크기/간격이 충족되는 경우만 적용합니다. 작은 케이스에서 배치가 불가능하면 원래 배치를 유지하며 이유를 표시합니다.
- **전고(全高) 코너 보강:** 기존 Ø6mm M3 나사 보스와 두 인접 벽 사이를 꽉 채운 직사각형 코너 웹으로 연결하고, 보스/웹을 **하판 접합면 Y=0부터 상판 안쪽 천장까지** 늘렸습니다. 천장과 0.45mm 겹쳐 연결하고 하판 체결홀 위치는 유지합니다. 자석 모드 역시 일체형 코너를 사용합니다.
- **기본 PCB 간섭 검사:** 라운드 내벽, 기둥, 다른 기판, 내부 높이를 확인합니다. 오류가 있으면 출력이 잠깁니다. 다만 **실제 전자부품의 돌출 높이, 배선, 기판 고정용 스탠드오프는 모델링하지 않으며 아직 검사 대상이 아닙니다.**
- **출력 검증 주의:** 강화된 코너 웹과 관통홀의 CSG 결과가 워터타이트인지, 실물 나사가 얼마나 버티는지는 실제 슬라이서·3D 프린터에서 시험해야 합니다.

## 이전 개선: 하몬드형 슬림 나사 기둥

- 기존 **Ø12.4 mm 기둥 + 시험용 M4 나사** 대신 **Ø6.0 mm 기둥 + 시험용 M3×0.5 나사**를 사용합니다. 나사 중심은 1590A의 28.5 × 82.6 mm, 1590B의 50.5 × 102.1 mm 중심 간격을 기준으로 하며 하판 홀에도 동일 좌표를 적용합니다.
- 둥근 바깥 윤곽으로부터 기둥까지 최소 1.2 mm를 확보하도록, 모서리가 큰 규격에서는 중심을 안쪽으로 소폭 이동합니다. **기둥이 외곽으로 돌출되지 않도록 계산**합니다.
- 기본 벽 두께를 2.4 mm로 조정했습니다. 편집기의 케이스 설정에서 **중앙 평면 내경**과 **코너 기둥 사이 유효 공간**을 실시간 확인하고, 공식 내부 평면 치수에 못 미치면 내보내기를 막습니다(비교 규격: 1590A / 1590B / 1590BB). 상판 2D 뷰에는 체결부 발자국을 점선으로 표시합니다.
- **1590B 비교:** 기존 기둥 사이 최소 폭 34.1 mm → 새 설계 44.5 mm. 제조사 도면의 코너 사이 44.5 mm와 일치합니다. 1590A 역시 22.5 mm 수준입니다.
- **주의:** 3D 프린터로 출력하는 M3 나사는 M4보다 취약합니다. 체결 강도/공차는 검증되지 않았습니다. 금속 M3나사+적절한 인서트를 사용한다면 인서트 외경에 맞게 보스를 다시 설계해야 합니다. **도면 기반 평면 비교만 수행**하며, 실제 Hammond 제품의 내부 높이, 경사벽, 방수 실링, 바닥 결합까지 완전 재현하지는 않습니다.

## 기능

- **케이스 선택:** 1590A, 1590B, 125B(1590N1 유사 외형, 동일 규격 아님), 1590BB. mm 단위 외형 치수 제공
- **하판 방식:** 3D 프린팅 M3 계열 시험용 나사 4개 + 보스/관통홀, 또는 자석 4쌍용 본체·하판 포켓
- **5면 홀 배치:** 상판, 전면, 후면, 좌측, 우측에 포텐셔미터, 6.35 mm 오디오 잭, LED, 풋스위치, 토글, DC 잭 배치. 홀 지름과 간섭 지름 개별 수정
- **배치 편집:** SVG 드래그, 방향키 0.5 mm / Shift+방향키 5 mm 이동, Delete 삭제, 중심/이웃 정렬 스냅(Shift로 잠시 해제), 벽까지의 거리, 가장 가까운 부품 거리, 가로·세로 자동 균등 분배
- **간섭 점검:** 간섭 영역 기준 최소 벽 여유 및 부품 간 간격 검사; 기본 오류가 있으면 STL 출력 잠금
- **3D 미리보기:** Three.js orbit/zoom, 본체·하판 분해도, 3D 클릭으로 편집할 면 선택, 선택 부품 강조
- **실제 홀 가공:** `three-bvh-csg`를 이용해 외형에서 내부 캐비티와 5면 관통홀/자석 포켓/나사 파일럿 홀을 부울 연산
- **STL 내보내기:** 본체 및 하판 STL, 나사 모드에는 테스트용 출력 나사 4개 STL까지 ZIP으로 다운로드. 단위는 mm로 해석하도록 설계
- **프로젝트:** 브라우저 로컬 자동 저장 + JSON 저장/불러오기 (서버로 업로드하지 않음)

## 실행

Node.js 22.12 이상 권장. 인터넷 연결된 환경에서:

```bash
npm install
npm run dev
```

Vite가 출력한 로컬 주소를 브라우저에서 여세요. 테스트 및 빌드:

```bash
npm test
npm run build
npm run preview
```

`dist/`가 정적 배포 파일입니다.

## GitHub Pages에 배포

1. GitHub에서 새로운 빈 저장소를 만들고 이 프로젝트의 **폴더 안 파일들**을 업로드하세요.
2. 저장소 기본 브랜치를 `main`으로 사용합니다. `.github/workflows/deploy.yml`이 `main`에 푸시되면 빌드/배포합니다.
3. 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택합니다.
4. Actions의 `Deploy Vite site to GitHub Pages` 실행이 성공하면 Pages URL이 제공됩니다.

Vite의 `base: './'` 설정으로 일반 루트 URL과 GitHub Pages 저장소 하위 경로를 모두 지원합니다.

## STL 구성

STL 내보내기는 검증 오류가 0개일 때만 가능합니다. 브라우저에서 아래 2개 또는 3개를 포함한 ZIP을 다운로드합니다.

| 파일 | 출력 대상 |
| --- | --- |
| `pedalform_<size>_body.stl` | 상판 + 4측면, 내부 캐비티, 체결 보스/자석 포켓, 배치한 관통홀 |
| `pedalform_<size>_bottom_lid.stl` | 아래쪽 탈착 하판, 관통홀/자석 포켓, 끼움 정렬 탭 |
| `pedalform_<size>_M3_printable_screw_x4_TEST.stl` | 나사 방식에서만 추가되는 실험용 4개 출력 나사 |

- 원점/방향: 상판 외측은 Y=높이 방향입니다. 본체는 밑면 Y=0에서 위로, 하판은 원본 조립 좌표에서 -두께~0으로 구성되며 **STL 출력 시 하판을 Y=0 이상으로 평행 이동**합니다.
- 슬라이서에서 **단위를 mm**로 지정하고, 본체는 일반적으로 **상판 외측을 빌드 플레이트에 닿게 뒤집어서** 출력하는 방향부터 검토하세요(부품 홀 주변 첫 레이어와 브리징을 확인). 하판은 평평한 면으로 출력하면 됩니다. 실제 출력 방향을 선택하세요. STL에는 단위 정보가 내장되지 않습니다.
- CSG 라이브러리에서 반환한 지오메트리의 `drawRange`를 직접 정리하여 STLExporter에 넘깁니다. 그래도 복잡한 배치/홀 간섭에서 메쉬가 non-manifold가 되는지 **슬라이서 검증이 필수**입니다.
- **출력용 나사:** 약 M3×0.5 형상을 본뜬 시험용 스레드, Ø2.45 mm 파일럿 홀, Ø3.45 mm 하판 관통홀, Ø6.0 mm 기둥을 사용합니다. 기둥 가장 얇은 원형 단면은 반지름 방향 약 1.775 mm입니다. 실험용으로 **FDM에서 나사산 뭉개짐/파손 가능성**이 있고 ISO 규격 적합성이나 체결 강도를 보증하지 않습니다. 자주 탈착할 경우 검증된 금속 고정구/인서트 사용을 권장하며 인서트 외경에 맞춘 재설계가 필요할 수 있습니다.
- **자석:** 기본 지름 5 mm × 두께 2 mm 자석을 가정하며, 양쪽 포켓에는 지정한 공차가 반영됩니다. 출력 전에 접착제/자석 극성/간격을 확인하세요. 자석은 STL에 포함되지 않습니다.
- **부품 간섭:** 2D 점검은 각 면의 평면 간섭 지름과 경계 간격만을 계산합니다. 부품의 실제 내부 깊이, PCB, 배선, 코너 사이의 3D 간섭, 나사 체결 공차, 출력을 위한 서포트 가능성 등은 별도로 확인해야 합니다.

## 내부 평면 비교 기준

| 모델 | 공식 도면 평면 내경 폭 × 길이 (mm) | 본 프로젝트 기본(2.4 mm 벽) 평면 내경 (mm) | 나사 기둥 사이 폭 × 길이 (mm) |
| --- | --- | --- | --- |
| 1590A | 33.70 × 87.80 | 33.7 × 87.8 | 22.5 × 76.6 |
| 1590B | 55.45 × 107.05 | 55.7 × 107.6 | 44.5 × 96.1 |
| 1590BB | 87.16 × 112.66 | 89.2 × 114.7 | 약 77.7 × 103.2 |
| 125B | 공식 Hammond 1590N1과 동일 규격이 아님 | 61.6 × 117.2 | 케이스 설정에서 자동 계산 |

표의 *평면 내경*은 `외형 − 2 × 설정 벽 두께`이며 사각형 중앙부 기준입니다. **제조사 단면 도면의 내부 높이 및 구배와 완전 동일하다는 의미는 아닙니다.**

## 대표 외형 치수 (명목값)

| 규격 | 너비 × 길이 × 높이, mm |
| --- | --- |
| 1590A | 38.5 × 92.6 × 31.0 |
| 1590B | 60.5 × 112.4 × 31.0 |
| 125B / 1590N1 크기 | 66.4 × 122.0 × 39.4 |
| 1590BB | 94.0 × 119.5 × 34.0 |

표는 하판을 포함한 **조립 높이 명목값**입니다. 기본 프로파일에서 본체 높이는 이 값에서 기본 하판 두께 3.2 mm를 뺀 수치이며, 하판 두께를 변경하면 조립 높이도 달라집니다. 제조사의 모델 및 생산 버전에 따라 치수가 다릅니다. 각 케이스 모델의 내벽 경사, 라운드, 나사 위치, 조립 높이, 하판 플랜지 등을 단순화했습니다. 외형 치수 시작점 참고:

- [Hammond 1590B 제품 도면](https://www.hammfg.com/files/parts/pdf/1590BLG.pdf)
- [Hammond 1590 series catalogue](https://bitsavers.org/components/hammondManufacturing/Hammond_Manufacturing_Small_Cases.pdf)

```text
src/
```

## 알려진 제한 / 다음 개선

- 2D 자동 간격은 같은 면의 모든 부품을 **한 축으로** 균등 배치합니다. 선택한 부분집합만 정렬하거나 심도별 3차원 충돌은 아직 지원하지 않습니다.
- 실물 부품 모델 라이브러리(제조사별 스위치/잭), 돌출 부품의 3D 간섭 검증, 홀 카운터보어/카운터싱크, 실제 PCB 고정 스탠드오프/마운팅홀은 후속 작업입니다.
- 자석의 실제 접착·압입 공차와 3D 출력 나사는 출력 테스트가 필요합니다.
- CSG에서 인접하거나 겹치는 다수의 홀은 기하학적 결함을 만들 수 있습니다. STL 워터타이트 검사 및 사용자 지정 공차/프린터 프로필을 추가할 필요가 있습니다.

상단 **3MF 다운로드** 버튼으로 Bambu Studio에서 열 수 있는 표준 3MF Core 파일을 직접 생성합니다. 케이스 본체와 하판은 별도 3D 오브젝트이며, 각 오브젝트에는 다른 색상 힌트가 있습니다. Bambu Studio에서 두 오브젝트를 불러온 후 AMS 필라멘트 색상을 직접 지정하고 출력 방향을 정하세요. Bambu 전용 프린터 프로파일과 AMS 슬롯 배정은 포함하지 않습니다.
